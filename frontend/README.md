# Smart Food Management & Redistribution System - Frontend

This is the frontend React application.

## 🛠️ Setup Instructions

1.  **Navigate to the folder**:
    ```bash
    cd frontend
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Critical Dependencies**:
    The project uses Leaflet for map-based features. If you see "Module not found" errors, run:
    ```bash
    npm install leaflet react-leaflet
    ```
4.  **Start the app**:
    ```bash
    npm start
    ```

## 🎨 Features
- **Organization Shopping Dashboard**: A premium dashboard for managing marketplace interactions, featuring a sticky header, hero section, and flash deals.
- **Location Picker**: Interactive map for selecting delivery/pickup locations.

## Available Scripts

- `npm start` - Runs the app in development mode
- `npm run build` - Builds the app for production
